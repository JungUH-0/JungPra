# 정마트 — 마트 재고·판매 관리 프로그램

강의 중에 만든 실습. **같은 프로그램을 네 번 다시 만들면서** 콘솔 → 함수 분리 → Flet GUI로
옮겨간 기록이다. 2026년 4월 작성.

생활용품·식료품 이름 목록에 무작위 ID·재고(1~50개)·가격(1,000~10,000원)을 붙여 매장을 만들고,
손님은 물건을 사고 관리자는 재고·가격·할인·매출을 관리한다.

---

## 단계별 파일

| 순서 | 파일 | 형태 | 이전 단계에서 바뀐 것 |
|---|---|---|---|
| 1 | `markettest.py` | 콘솔 | 전부 `while` 중첩 한 덩어리. 관리자(매출·재고·가격 변경), 매장(구매), 랜덤 할인 |
| 2 | `marketdef.py` | 콘솔 | 화면마다 함수로 분리. 원가와 현재가격을 나누고, 할인 품목 직접 선택(10~40%) 추가 |
| 3 | `marketflet.py` | Flet | 화면 배치 스케치. 상품은 자리표시(상품 A·B·C)이고 실제 데이터와 연결 안 됨 |
| 4 | `jungmart.py` | Flet | **완성본.** 실제 데이터 연결, 장바구니·결제, 매출 현황, 시작 시 깜짝 할인 |

`marketdef.py` 맨 위에는 함수로 나눌 때 고민했던 질문(while문을 어디에 둘지, 중첩이 많으면
함수에서 무슨 문제가 생기는지)이 주석으로 남아 있다.

---

## 실행

Python **3.12 이상**이 필요하다 — f-string 안에서 같은 따옴표를 겹쳐 쓴 곳이 있어서
(`f"{market[k]["품명"]}"`) 그 아래 버전에서는 문법 오류가 난다.

```bash
pip install flet
python jungmart.py
```

콘솔 버전은 `python markettest.py`, `python marketdef.py`로 바로 실행된다.

---

## jungmart.py 사용법

**구매 페이지**
- 왼쪽 목록에서 상품을 누르거나 이름으로 검색 → 수량 입력 → 장바구니 담기 → 결제하기
- 위쪽 빨간 띠에 할인 중인 상품이 표시된다
- 이 화면의 `메인` 버튼은 잠겨 있고 **F12**를 눌러야 풀린다 — 손님이 관리 화면으로 못 넘어가게 한 장치

**관리 페이지**
- 왼쪽 목록에서 상품 선택 → 오른쪽 버튼으로 수정
- 재고수정(확인창이 뜬다) · 가격변경(할인율 자동 계산) · 할인율 적용(최대 50%) · 매출현황(당일·이번 주)

---

## 현재 한계

- **매출이 파일에 저장되지 않는다.** `savefile()`이 정의만 되어 있고 호출되는 곳이 없어
  `sales_data.txt`가 만들어지지 않는다. 매출현황은 이번 실행 중에 결제한 것만 보여준다
- 상품 목록·재고·가격은 실행할 때마다 무작위로 새로 만들어진다
- `markettest.py`는 구매해도 총 매출에 더해지지 않아 매출 확인이 항상 0원이다
  (`marketdef.py`에서 고쳐짐)
