# 학습 인계

## 목표와 설명 방식
교수님 요구는 다른 학생들이 코드를 이해하고 따라 실행할 수 있는 프로젝트다.
사용자는 Python 기초, NumPy, pandas, FastAPI를 학습했다.
한국어로 단계별 설명을 제공하고 파일 생성/수정 위치와 실행 명령을 명확히 안내한다.
사용자는 직접 파일을 만들어 실행해주는 것도 원한다.

## 현재 합의
TF-IDF + Ridge를 충분히 이해하고 검증 실험을 한 다음 LSTM으로 확장한다.
바로 LSTM 전체 구현을 진행하지 않는다.
LSTM에서도 실제 평점 회귀를 유지해 동일 조건에서 비교할 계획이다.

## 완료 사항
- datachk.py, split_data.py, train_model.py의 실제 원본 코드를 확인하고 이 폴더에 복사했다.
- clean 26,432행에서 review+rating 중복 111행 제거, ready 26,321행.
- ready의 결측/빈 리뷰/완전 중복 0. 서로 다른 평점이 붙은 동일 문구 21종류는 보존했다.
- train 21,052행, test 5,269행. 분리 방식은 고유 리뷰 목록 sample(frac=0.2, random_state=42)와 isin.
- 분리 CSV 재검증 완료: 리뷰 교집합 0, 입력 행 전부 보존.
- 사용자 모델 실행 결과: baseline MAE 0.8913, Ridge MAE 0.7464, 감소량 0.1450점(반올림 전 계산).
- predictions CSV 경로를 제공받았지만 내용은 아직 직접 검토하지 않았다.
- 모델·변환기 저장, 직접 리뷰 입력, API, LSTM은 미구현이다.

## 현재 학습 위치
최근 TF-IDF와 Ridge의 fit 차이, alpha, 과적합/과소적합을 설명했다.
문자 1~3그램과 희소 행렬의 shape도 설명했다.
다음은 실제 특징 이름과 리뷰 한 개의 TF-IDF 값을 출력하는 실습이다.

## 다음 단계
1. 실제 코드와 파일을 읽기 전용으로 확인한다.
2. get_feature_names_out()으로 특징 이름을 확인한다.
3. 리뷰 한 개의 희소 행에서 0이 아닌 특징과 값을 출력한다. 전체 행렬을 toarray()로 바꾸지 않는다.
4. TF-IDF는 표현을 수치화하고 Ridge가 평점과의 관계를 학습한다는 점을 설명한다.
5. 기존 학습용을 리뷰 문구 단위로 학습/검증 분리한다. 벡터화는 학습 부분에만 fit한다.
6. 우선 alpha=1,10,100만 검증 MAE로 비교한다.
7. 설정 선택 후 기존 학습용 전체로 재학습하고 최종 평가한다. 기존 평가 점수는 이미 본 초기 결과임을 명시한다.
8. 오차 사례와 재현 설명을 정리한 뒤 LSTM으로 확장한다.
