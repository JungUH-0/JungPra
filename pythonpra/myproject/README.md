# 개인 AI 비서 (Gesture · Voice · LLM Assistant)

웹캠과 마이크로 **손동작 · 전신 포즈 · 음성**을 인식해서 PC를 제어하는 개인 비서.
실행할 명령은 **로컬 LLM(Ollama)** 이 자연어로 해석하므로, 코드를 고치지 않고
"메모장 열어줘" 같은 문장만으로 제스처에 원하는 동작을 새로 지정할 수 있다.

모든 처리(포즈 인식 · 음성 인식 · LLM 해석)가 **로컬에서** 돌아가며 외부 서버로
나가는 데이터가 없다.

---

## 구조

```
[모드 A] cameramodule.py (손동작 인식) ─┐
                                        ├→ main.py ─→ commandmodule.py ─→ windowcontrol.py
[모드 B] posemodule.py   (전신 포즈)  ─┘  (모드 전환)   (LLM 해석 + 실행)     (실제 OS 동작)
                                             ↑
                          voicemodule.py (음성) ┘
                          audiomodule.py (박수 - 모드 전환 신호)
```

**설계 원칙**

- **인식과 실행의 분리** — 인식 모듈은 "무슨 동작인지"만 판정해서 이름으로 보고하고,
  실제로 무엇을 실행할지는 `main.py`가 `commandmodule`을 통해 결정한다. 덕분에
  사용자가 제스처에 다른 명령을 등록해도 인식 코드를 건드릴 필요가 없다.
- **명령 엔진 공유** — 손동작 · 전신 포즈 · 음성 세 입력이 `commandmodule` 하나를
  공유한다. 명령 종류를 추가하면 세 입력 모두에 동시에 적용된다.
- **한 번에 한 인식기만** — 손 인식과 포즈 인식을 동시에 돌리면 FPS가 떨어지고
  제스처끼리 충돌하므로, 모드를 나눠 한쪽만 실행한다.
- **화이트리스트 실행** — LLM이 만들어낸 문자열을 그대로 실행하지 않고, 미리
  등록된 동작 목록에 있는 것만 실행한다.

## 기능

### 손동작 모드 (기본)

| 제스처 | 동작 |
|---|---|
| 손바닥 중심점 이동 | 마우스 커서 이동 (떨림 보정 + 감도 증폭) |
| 엄지 + 검지 붙이기 | **좌클릭** — 붙이면 누름, 떼면 뗌 (클릭·드래그 모두 가능) |
| 엄지를 손바닥 중앙으로 넣기 | **우클릭** |
| 약지·새끼 말고 손 전체 위/아래 | **휠 스크롤** |
| 주먹 + 엄지 위 (1초 유지) | **예 / 동의** |
| 주먹 + 엄지 아래 (1초 유지) | **아니오 / 거절** |
| 스와이프 업 | 창 복원 *(커스텀 명령 등록 시 대체)* |
| 스와이프 다운 | 창 최소화 *(커스텀 명령 등록 시 대체)* |
| **손날** + 스와이프 다운 | 창 닫기 **확인 요청** → 예/아니오로 확정 |
| 엄지 + 중지 / 약지 / 새끼 | **커스텀 명령 슬롯 3개** |
| 손등 3초 유지 | **음성 명령 녹음 시작** |

> 클릭류(좌·우클릭, 커스텀 슬롯)는 손이 **정면(손바닥)** 일 때만 판정된다.
> 손등·손날 방향에서는 카메라의 2D 투영 때문에 손가락이 겹쳐 보여 오작동하기 때문.

### 전신 포즈 모드

상체 9개 키포인트(코 · 귀 · 어깨 · 팔꿈치 · 손목)를 인식해 **22차원 특징**을 추출한다.
어깨 중점을 원점, 어깨 너비를 스케일로 삼아 정규화하므로 **화면상 위치와 카메라
거리에 영향을 받지 않는다.**

| 특징 | 구성 |
|---|---|
| 정규화 좌표 | 9개 × (x, y) = 18 |
| 팔꿈치 각도 | 좌 · 우 = 2 (0=굽힘, 1=폄) |
| 머리 방향 | 돌리기 · 기울이기 = 2 |

자세 **분류(학습)는 아직 미구현** — 현재는 특징 추출과 시각화까지만 동작한다.

### 모드 전환

**양손을 모아 1초 유지**하면 손동작 ↔ 전신 포즈 모드가 전환된다.
(`main.py`의 `MODE_SWITCH_REQUIRE_CLAP = True`로 바꾸면 "박수 + 양손 모임"을 요구하는
방식으로 되돌릴 수 있다. 소음이 심한 환경을 고려해 기본값은 박수 없이 동작.)

### 음성 명령

| 트리거 | 녹음 종료 |
|---|---|
| **"웨이크"** 발화 | 말이 끝나고 1.2초 무음이면 자동 종료 |
| **손등 3초 유지** | 손을 떼는 순간 종료 (무전기 방식) |

Whisper(`medium`, GPU)로 텍스트 변환 → LLM 해석 → 즉시 실행. 음성 명령은 제스처
슬롯에 등록할 필요 없이 그때그때 자유롭게 말하면 된다.

### LLM이 실행할 수 있는 동작

| 분류 | 목록 |
|---|---|
| 창 제어 | 최소화 / 닫기 / 복원 |
| 모니터 | 끄기 / 켜기 |
| 앱 실행 | chrome, edge, notepad, calculator, explorer, cmd, powershell |
| 단축키 | copy, paste, cut, undo, redo, save, select_all, new_tab, close_tab, switch_window |
| 미디어 키 | volume_up/down, mute, play_pause, next_track, prev_track |
| 사이트 열기 | youtube, google, gmail, naver, github |

## 설치

**환경**: Windows (win32 API 사용), Python 3.10, NVIDIA GPU 권장 (Whisper용)

```bash
pip install mediapipe opencv-python numpy pillow pywin32 sounddevice requests faster-whisper
```

| 패키지 | 확인된 버전 | 용도 |
|---|---|---|
| mediapipe | 0.10.9 | 손 · 얼굴 · 포즈 랜드마크 |
| opencv-python | 5.0.0.93 | 카메라 입출력, 시각화 |
| numpy | 2.2.6 | 수치 연산 |
| pillow | 12.3.0 | 화면 한글 텍스트 렌더링 |
| pywin32 | 312 | 마우스 · 키보드 · 창 제어 |
| sounddevice | 0.5.5 | 마이크 입력 |
| requests | 2.34.2 | Ollama API 호출 |
| faster-whisper | 1.2.1 | 음성 인식 |

**Ollama 설치 및 모델 준비**

```bash
winget install --id Ollama.Ollama -e
ollama pull qwen2.5:3b-instruct
```

Whisper 모델(`medium`, 약 1.5GB)은 최초 실행 시 자동으로 내려받는다.

## 실행

```bash
python main.py
```

카메라 창에서 `q`를 누르면 전체 종료.

**제스처에 명령 등록하기**

```bash
python commandmodule.py
```

1. 제스처 이름 입력 (`pinch_middle`, `pinch_ring`, `pinch_pinky`, `swipe_up`, `swipe_down`, `close_confirm`)
2. 하고 싶은 일을 자연어로 입력 (예: `"유튜브 열어줘"`)
3. LLM이 해석해서 `commands.json`에 저장

`commands.json`은 실행 중에도 매번 다시 읽으므로 **`main.py` 재시작 없이 바로 반영**된다.
항목을 지우거나 파일을 통째로 삭제해도 안전하며, 같은 이름으로 다시 등록하면 덮어쓴다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `main.py` | 전체 오케스트레이션 — 모드 전환, 각 모듈의 결과를 명령으로 연결 |
| `cameramodule.py` | 카메라 소유 + 손동작 인식 (커서 · 클릭 · 휠 · 스와이프 · 커스텀 슬롯) |
| `posemodule.py` | 전신(상체) 포즈 인식 — 카메라는 `cameramodule`에서 프레임을 넘겨받음 |
| `audiomodule.py` | 박수 감지 (모드 전환 신호용) |
| `voicemodule.py` | 웨이크워드 감지 + 명령 녹음 + Whisper 변환 |
| `commandmodule.py` | LLM 해석 + 명령 등록/실행 (세 입력이 공유) |
| `windowcontrol.py` | 실제 OS 동작 — 마우스 · 키보드 · 창 · 모니터 제어 |
| `commands.json` | 제스처 ↔ 명령 매핑 (자동 생성, git 제외) |
| `debug_*.txt` | 진단 로그 (자동 생성, git 제외) |
